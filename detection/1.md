## Control the robot arm
```bash
ros2 topic pub -1 /ArmController/target_joints interbotix_xs_msgs/msg/JointGroupCommand "{
  name: 'arm', 
  cmd: [0.0, -0.3, 0.4, 1.0]
}"
```

## Control the gripper
```bash
ros2 topic pub -1 /ArmController/target_gripper interbotix_xs_msgs/msg/JointGroupCommand "{
  name: 'gripper', 
  cmd: [1.57]
}"
```

## Move the pantile for enabling seeing the object

ros2 topic pub /pan_tilt_cmd_deg pan_tilt_msgs/msg/PanTiltCmdDeg "{yaw: 0.0, pitch: 37.0, speed: 20}"

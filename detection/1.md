```bash
ros2 launch realsense2_camera rs_launch.py
```

## To launch the arm controller
```bash
python3 src/arm/arm_controller.py
```

## To launch the detection
```bash
python3 src/detection/aruco_detection_ros.py
```

## Control the robot arm
```bash
ros2 topic pub -1 /ArmController/target_joints interbotix_xs_msgs/msg/JointGroupCommand "{
  name: 'arm', 
  cmd: [0.0, -0.3, 0.4, 1.0]
}"
```

## Control the gripper
```bash
ros2 topic pub -1 /ArmController/target_gripper interbotix_xs_msgs/msg/JointGroupCommand "{
  name: 'gripper', 
  cmd: [0.80]
}"
```

## Move the pantile for enabling seeing the object
```bash
ros2 topic pub /pan_tilt_cmd_deg pan_tilt_msgs/msg/PanTiltCmdDeg "{yaw: 0.0, pitch: 30.0, speed: 5}"
```
